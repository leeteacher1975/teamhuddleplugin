관리자 비밀번호 확인

비밀번호를 입력해야 데이터 현황 조회·다운로드·초기화 화면을 볼 수 있어요.

현재 데이터 현황

각 활동 API에서 실시간으로 불러온 값이에요.

-
① 투표 참여
-
② 케이스 공유
-
③ 아이디어
-
④ 실천 다짐

전체 데이터 다운로드

먼저 최신 데이터를 불러온 뒤 다운로드하세요. 활동별 CSV는 엑셀에서 바로 열 수 있어요.

전체 초기화

비밀번호 확인 후 초기화됩니다. 초기화 전에 반드시 위에서 데이터를 먼저 다운로드해두세요. 되돌릴 수 없어요.
